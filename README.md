## Как поменять цену, срок акции или телефон

1. Откройте файл `content/site.json` прямо на GitHub и нажмите на карандаш (Edit).
2. Меняйте только текст в кавычках справа от двоеточия. Кавычки и запятые не трогайте.
3. Нажмите **Commit changes**. Через 1–2 минуты сайт пересоберётся сам.

## Как это устроено

- `build.py` собирает страницы из `content/site.json` в папку `_site/`. Внешние библиотеки не нужны, только Python 3.
- `.github/workflows/deploy.yml` после каждого изменения в `main` запускает сборку и выкладывает сайт на GitHub Pages.
- Фото лежат в `assets/img/` в формате WebP. Шрифты Playfair Display и Montserrat хранятся локально в `assets/fonts/`.
- Цвета и сетка задаются в `assets/css/style.css`, форма и цели Метрики — в `assets/js/main.js`.

Собрать локально: `python3 build.py`, затем открыть `_site/index.html` через любой локальный сервер.

## Что осталось подключить

- [ ] **Заявки.** В `site.json` → `integrations.form_endpoint` нужно указать адрес приёма заявок (вебхук amoCRM). Пока поле пустое, форма предлагает позвонить или написать в ВК.
- [x] **Яндекс Метрика** — счётчик 113708808 (логин Sokol-96ya), Вебвизор включён. Цели (целевые события): `lead` — заявка с формы, `phone` — клик по телефону, `vk` — переход в ВК, `cta` — нажал «Записаться», `price` — доскроллил до цен. Проверить срабатывание: открыть страницу с `?_ym_debug=2` и посмотреть консоль браузера.
- [ ] **Пиксель ВК Рекламы.** Номер вписать в `integrations.vk_pixel_id`.
- [ ] **Домен.** Добавить файл `CNAME` с доменом, настроить DNS и поставить `"base_path": ""` в `site.json`.
- [ ] **Длительность массажа лица и вакуума.** Поля `duration` и `vacuum_duration`.
- [ ] **Противопоказания к вакуумному массажу.** Нужен список от мастера.
- [ ] **Мастера.** Проверить, что на общем фото только те, кто работает сейчас.
